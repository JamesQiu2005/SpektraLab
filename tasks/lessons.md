# Lessons

- 复用跨平台后端前，以当前 CMake 变量名核对 PowerShell 构建脚本；历史验收文档不能证明当前入口仍可用。

- 触发：部署后接条件构建。预防：确认部署退出码和构建日志存在，再报告编译状态；环境失败时保持下游任务未运行。
- 触发：同版本 Qt 归档构建日期发生变化。预防：从官方来源刷新固定包清单并验证现有校验，不将更新包链接等同于 SDK 运行验收。
- 触发：Windows 程序以 0xC0000135 静默退出且没有版本输出。预防：先按动态链接 runtime 缺失排查 PATH，而不是把空 stdout 解释为版本不匹配。

- 触发：功能已经移植，文档仍按旧的 `windows_unported.*` 拒绝层描述为缺失。预防：删除失效拒绝代码后，用功能边界测试和实际渲染结果更新状态文档，不以文件存在推断能力。

- 触发：Windows 测试用固定小写扩展名匹配原始 RAW。预防：从输入文件名保留大小写构造期望值，不把 Windows 路径不区分大小写推广到字符串比较。
