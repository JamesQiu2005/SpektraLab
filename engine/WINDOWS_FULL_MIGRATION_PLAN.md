# Windows 完整功能迁移评估与路线图

评估日期：2026-10-18。状态：**实施中；下表保留最初审计差距，阶段验证进展见末尾。未完成全部功能与发布验收。**

## 1. 对齐目标与证据边界

本轮目标是把当前 macOS 产品的完整功能带到 Windows，保留现有胶片模型、精度、性能和内存优化。可以分阶段实现；不能用“界面出现了开关”或“补齐几个着色器”代替端到端功能验收。

| 对象 | 本次核对的基线 |
|---|---|
| macOS 上游 | 主线 `f1440bd1e22ffe0acf719852c51277b2f1692cb4`，最近提交 2026-10-14；当前发布版本 1.3.3（18） |
| 本地 Windows | `Windows_Linux`，HEAD `9c03b68d31bc6864d94c843f34ae47e36e98ddc5`，以及现存未提交的内存优化工作 |
| 远端 Windows | `Windows_Linux`：`e8978fa1100bd0ff42a09ba8239ecc0f1666e328` |
| 方法 | 对照远端固定提交的文件树与源码，逐项检查本地引擎、宿主协议、TypeScript 界面和 Swift 实现；本轮没有重新构建或运行 GUI/GPU 验收 |

上游主线和远端 Windows 的历史与本地已经分叉，不能把提交数量差异当成功能差异。按文件内容比较，远端 Windows 相对本地已提交版本有 11 个修改文件，主要涉及文档、参数、片边和资源生成；大量删除是设计/研究文档退出版本管理。主线又不包含本地全部 Windows 导出和内存改进。后续应先保全当前改动，再按模块合入，不能直接用主线覆盖 Windows。

可复查材料保存在 `D:/SpektraLab-win/validation/feature-audit-20261018/`：两份完整远端树、内容差异清单、关键上游源码快照。旧 `WINDOWS_FEATURE_COVERAGE.md` 仍含 Qt 阶段描述，`desktop/PARITY.md` 也未纳入全部近期工作；本报告用于当前规划，旧表只作历史记录。

“完全迁移”的建议定义：固定上述 Mac 基线，覆盖其公开可用功能、参数保存/恢复、预览、批量和导出。Apple 专用框架用 Windows 等效实现，并单独验收差异。RAW 解码器不同，不能承诺与 Apple 私有解码器逐字节一致。后续 Mac 更新单列增量，不在每阶段中途无限扩大目标。

## 2. 已具备的基础，无需重新迁移

- 彩色正片/负片和相纸主流程；多层/简单颗粒、光晕、辉光、测光、高光增强、黑白端点校正、相纸 EDR 数学和分条执行已有实现。是否达到最终 Mac 数值一致性，仍需外部参考验收。
- ProPhoto 工作空间、GPU 后期、曲线/四区色彩平衡、裁切/旋转/翻转/缩放，自动预览及完整质量更新。
- 自动/sRGB/Display P3 显示选择；主图、导航、直方图、缩略图，以及原图/分割对照入口。原图来源语义仍有差异，见下表。
- 批量导入、多选、六组设置剪贴板及同步、当前照片撤销/重做、同路径侧车参数保存、中文路径和基础崩溃恢复。
- JPEG、PNG、TIFF 直接后端导出，预设、尺寸、命名、覆盖保护、取消；现有三种输出空间为 sRGB、P3、ProPhoto。
- 相纸 `.cube` LUT、旧归一化负片密度导出已有后端路径。它们不等于新版 Cineon DI 功能。
- RAW OpenMP 解码和 GPU 数据驻留；现存未提交工作又加入 LibRaw 提前释放、空闲池回收、暂存限额、TIFF 流式写入及批量缓存暂存。后续不能以新功能为由回退这些措施。

### 必须保留的实现细节

**黑白体系（F01）**

上游从 1.3.3 正式开放 Tri-X 400、T-Max 100、Acros II、HP5 Plus 400 和 Multigrade IV RC。不要只复制五个 profile：默认相纸滤色包 CMY 为 `0/0/68`；四种胶片颗粒基准分别为 `1.70 / 0.74 / 0.64 / 1.49`；黑白片禁用彩色子层颗粒，银盐纸禁 EDR。新 `resources_product` 与原 `resources` 分开维护，打包时叠加并保留来源说明；引擎不会自动读取产品相纸滤色配置，宿主必须发送正确参数。

选片、重置、粘贴和读侧车均要防止不兼容胶片/相纸配对。新增镜头滤色参数影响画面感光响应，不应影响片边、雾化与日期曝光；相关共享代码一并核对。Mac 尚未开放镜头滤镜/相纸等级控件，不在首批 UI 范围内。

**片边/日期/半格（F06–08）**

`overscan.cpp` 使用 Accelerate、CoreGraphics 和 CoreText，除了四个着色器还需要跨平台栅格和字体替代。不得随包分发无授权 Apple 字体；先明确可分发字体和布局差异验收。日期不是最终照片上的普通水印。半格也不是拼接两张已经输出的 JPEG，而是共享材料流程中的两帧成像。

**Cineon（F05）**

现有 `spk_export_di` 的归一化负片密度加相纸 LUT，与 `spk_render_digital_intermediate` 的 Cineon 不等价。新模式必须使用独立的查看转换和导出语义；不能解锁开关后沿用普通 ProPhoto 后期路径。无普通 RGB ICC 的 Cineon 文件和可查看预览页应明确区分。

**导出与显示（F03/04/12/16）**

保持普通预览矩阵转换与导出 CAM16 映射的区分。软打样应走真实导出像素处理链，再到显示空间；不是直接把色域下拉框重命名。需保持现有后台直接导出，不能重新引入整图经前端往返。软打样的编解码边界应与 Mac 一致，JPEG 压缩伪影是否额外模拟需明确说明。

## 4. 不应误列为当前 Mac 的功能缺口

- Mac `FeatureFlags` 中 Masks / Tone Mask 仍关闭。Vulkan 确实还缺两个 Tone Mask 内核，但它们属于后续实验/API 覆盖，不抢在公开功能前面。
- 相纸 EDR 已迁移；Mac 的 `wantsExtendedDynamicRangeContent` 也是 `false`，真正 HDR 显示不是当前 Mac 已启用功能。
- Mac 枚举已安装 ICC，但引擎转换只接受已知内置空间；不能因此承诺“任意 ICC 输出”已经存在。复杂**输入** ICC 的支持是另一项差距。
- Mac PNG 实际是 8 位，16 位选项会改为 TIFF；不凭空增加“缺 PNG16”的迁移任务。
- Mac 设置剪贴板同样不复制裁切和 Post-Dev，当前六组不是遗漏两组。
- Windows 启动空图库、单独打开文件不恢复上次目录是已确认行为；递归导入文件夹与 Mac 平面导入的差异不自动视作 bug。
- 原生标题栏、快捷键、安装器、权限和显示管理采用 Windows 对应方式，不要求复制 Apple 平台机制。

建议**下一批从 M0 + F01 开始**，同时独立实现 F03/04；之后进入场景置位。不要一次性解除所有 Windows 功能门控。每项只有完成引擎、宿主、界面、持久化、导出及测试后才向用户开放。

当前 Metal 内核中有 8 个尚无 Vulkan 对应：DI 1 个、场景置位 1 个、Tone Mask 2 个、片边 4 个。这个数字只说明着色器缺口，不代表还剩 8 项工作或可据此估算完成百分比。

## 6. 完整迁移验收标准

1. **功能闭环**：每项验证默认/边界参数、快速交互、撤销、侧车保存重开、复制/同步、主图/导航/直方图/缩略图、单张和批量导出。窗口中确实启用且结果正确，才标记完成。
2. **成像参考**：先固定同一份 float32 解码输入，在 Mac/Metal 与 Windows/Vulkan 比较节点和全图；遵循已有误差标准。关闭功能应保持原旁路结果。随机效果使用固定种子、同一次缓存或统计检验，不跨次随机输出强求哈希相同。
3. **RAW 单列**：建立“机型 × 压缩方式 × 解码模式 × WB/方向 × 内存”矩阵。现有 Sony ARW 可回归；Nikon HE/HE* 继续按当前不支持处理；80MP IIQ 需要实际文件，扩展名接受不代表成功支持。Apple/LibRaw 解码差异与胶片引擎误差分别记录。
4. **导出与 proof**：PNG/TIFF 解码像素、ICC/EXIF、尺寸/方向、覆盖保护、中文路径、磁盘失败；JPEG 保持已有采样和质量约定。软打样验证其配方链与真实导出链一致；Cineon 验证数值、查看 LUT、预览页和色彩标记。
5. **资源与速度**：沿用现有完整调用计时范围，固定输入/参数，记录首跑/热跑和峰值内存；至少 20 次批量/切图、尺寸变化、取消/错误后释放检查。保留 staging 限额、空闲回收、流式 TIFF 和批量会话预算。新增特性不能靠降低画质或漏效果满足性能要求。
6. **平台与发布**：本机 NVIDIA 测试不能替代 Intel/AMD；真实 Mac 对照、广色域屏/跨屏、Windows 高 DPI 和最终显示精度需单列。最终安装/便携资源路径、驱动与 WebView2 依赖必须实测；制作发布包和 Git 提交仍按用户明确要求执行。
7. **完成判定**：F01–F18 全部完成或有经确认的平台等效方案，公开菜单/入口逐项验收，已关闭的上游实验功能另表跟踪。存在未验证的替代实现时，不宣称完全迁移完成。
