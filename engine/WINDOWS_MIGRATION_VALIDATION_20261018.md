- Mac/Metal 仅共享源码兼容审查，未进行 Xcode 构建及同输入像素对照。
- Intel/AMD、真实广色域跨屏、最终显示器 10 位链路未实测；浏览器 float16 支持不能证明屏幕位深。
- 80MP IIQ 暂无样本，未宣称其解码与峰值内存已验证。现有 Nikon HE 样本仍明确拒绝，随后正常图像可继续打开。
- Lensfun 为 Windows 平台等效方案，未证明与 Apple 镜头校正逐像素相同。
- HEIC 当前限 SDR HEVC，拒绝 PQ/HLG；EXR 限 flat first-part RGB/Y，拒绝 deep。
- 持久缓存存储最终显示帧，后台仍需准备原生会话；不将命中显示缓存算作 RAW 解码完成。
- 上游仍隐藏的 Tone Mask / Masks 保持关闭，不伪装成已开放功能。
- Linux 构建脚本已同步依赖，本轮完整迁移未在 Linux 或 Wine 重跑，不能用 PR #11 的基线 CI 替代。

本包定位为 Windows 迁移测试版；上述跨平台成像与硬件验收完成前，不宣称完全像素一致。
