# grain-all

Data and scripts behind `../colour-film-granularity.md`: what each maker publishes
(`published_granularity.*`), what the engine renders (`engine_rms*`), and the per-film amount
(`per_film_grain_amount.json`). Re-run: `measure_all.py`, `linearity.py`, `default_amount.py` (see each
file's header). The fetched datasheet PDFs (`sheets/*.pdf`) are local only.
