# PARITY — the macOS app (`modern_UI/Spektrafilm`) → `desktop/`

What of the SwiftUI/Metal app this TypeScript (Tauri 2) port carries, area by
area. **ported** = the behaviour is here; **partial** = present with a stated
gap; **stub** = the controls are drawn and disabled with the reason;
**skipped** = deliberately not carried, with why.

Updated Windows scope (2026-10-27): the owner authorised restoring the Mac
features and UI. Film Edge, date back and scene latitude now run through the
real Vulkan backend; crop/compare/export geometry has an explicit film-frame
path. Cineon mode now uses the original shipped DI view for every host surface
and ordinary export; a dedicated raw Cineon endpoint writes untagged 16-bit
codes plus both original LUTs. Core contrast-mask kernels/host filtering are
tested; its product UI remains withdrawn as on the Mac. Half-frame recipe UI
includes per-hole print/Post-Dev, scope and dual-gate comparison, with real RAW
frontend/native three-format exports tested. Native select/reframe/history and full pair PNG click acceptance passed. Capability
gates continue to omit genuinely unavailable rows while preserving sidecars.
Windows native Film Edge/curve/wheel/undo interactions have been verified;
large edited GUI JPEG/PNG/TIFF16 exports at7311x6786 passed with nonneutral
curves/wheel/film edge and independent ICC/bit-depth readback. Windows native key single-dispatch, numeric Escape/Enter, rail resize/reset and
1100x680 client layout have also passed. Final package acceptance is recorded
separately from these interface checks. Mock layout tests are not proof of a real desktop render.

## Windows keyboard and numeric-field verification (2026-10-27)

WebView2-delivered Ctrl keydowns are handled instead of being silently deferred
to a Win32 menu that did not run them. Native C/Escape/Ctrl+E and two-step
Ctrl+Z/Ctrl+Shift+Z were checked against saved sidecars for single dispatch.
IME Process/physical-letter and focused-text guard cases have browser tests;
the native run uses the current input environment without changing OS settings.
Shared ScrubSlider and NumberField cancel an Escape-triggered synchronous blur
with a ref, before React applies the draft-state reset. Both originally committed
cancelled values (red0->2 and24->50); both cancel and normal Enter now pass in
the browser and actual Windows widgets. These changes do not modify the Swift
Mac app, material resources or the spectral pipeline.
